# AFTERHOURS
Beyond the screen lies a universe of stories. Welcome to AFTERHOURS( simply a NETFLIX clone), my frontend project.

**AfterHours** is a Netflix-inspired, responsive movie streaming platform interface built using **HTML5, CSS3, and Vanilla JavaScript**. It offers an interactive movie-browsing experience with a modern UI, allowing users to explore movies, filter by genre, search titles in real time, manage a personal watchlist, and discover random movies through the *Surprise Me* feature.

### ✨ Features
- 🎥 Cinematic hero section with a modern streaming-style design.
- 🔥 Trending Now section featuring popular movie titles.
- 🔍 Real-time, case-insensitive movie search.
- 🎭 Genre-based movie filtering across five categories.
- ❤️ Personal watchlist with add/remove functionality.
- 🎲 Surprise Me feature to discover random movies.
- 🌓 Dark and Light mode toggle.
- 🕒 Dynamic time-based greeting.
- 📱 Fully responsive layout for desktops, tablets, and mobile devices.
- 💾 LocalStorage integration to preserve watchlist and theme preferences.

### 🛠️ Tech Stack
- **HTML5** – Semantic structure
- **CSS3** – Responsive layouts, Grid, Flexbox, animations and themes
- **JavaScript (ES6)** – DOM manipulation, event handling, filtering and dynamic rendering
- **LocalStorage** – Client-side preference persistence

### 🚀 Getting Started
1. Clone this repository.
2. Open the project folder.
3. Launch `index.html` in your browser.

No frameworks, backend, or installation required.
